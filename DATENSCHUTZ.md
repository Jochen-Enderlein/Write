# Datenschutzerklärung für Write

Stand: 6. Oktober 2026 · [English version below](#privacy-policy-for-write)

## 1. Verantwortlicher

Jochen Enderlein – Anschrift und Kontakt siehe [Impressum](https://beerball.jochens-toller-server.de/impressum).

## 2. Das Wichtigste in Kürze

Write ist ein Programm, das auf deinem Mac läuft. Es gibt **kein Konto, keine Telemetrie, keine Analyse und keine Werbung**. Deine Notizen, der Suchindex, die Versionsgeschichte und deine Einstellungen bleiben auf deinem Gerät bzw. in dem Ordner, den du selbst auswählst. **Der Entwickler erhält keine dieser Daten.**

Die einzige Verbindung, die Write selbst ins Internet aufbaut, ist die **Update-Prüfung bei GitHub** (Abschnitt 4) – automatisch nur mit deiner Einwilligung.

## 3. Synchronisation über iCloud, Dropbox, Nextcloud o. Ä.

Write hat keinen eigenen Sync. Liegt dein Ordner in einem Cloud-Dienst, überträgt dieser Dienst die Dateien nach seinen eigenen Bedingungen. Write ist daran nicht beteiligt; Verantwortlicher ist der jeweilige Anbieter bzw. du selbst.

## 4. Update-Prüfung bei GitHub

**Was passiert:** Write ruft bei GitHub die Übersicht der veröffentlichten Versionen dieses Projekts ab. Gibt es eine neuere Version, lädt Write sie herunter; installiert wird sie erst beim Neustart.

**Wann:**

- automatisch beim Start und danach einmal täglich – **nur, wenn du das erlaubt hast** (Frage beim zweiten Start, Schalter unter _Einstellungen → Über Write_);
- sonst nur, wenn du selbst auf _Nach Updates suchen_ klickst.

**Welche Daten:** Bei jeder Anfrage erhält GitHub deine **IP-Adresse**, den Zeitpunkt, eine technische Kennung des Programms (`electron-builder`) und welche Dateien abgerufen werden. Beim Herunterladen eines Updates lässt sich daraus die installierte Write-Version ableiten. Inhalte deiner Notizen, Dateinamen oder Einstellungen werden **nie** übertragen.

**Zweck:** dir Fehlerbehebungen und Sicherheitsupdates bereitzustellen.

**Rechtsgrundlage:** für die automatische Prüfung deine Einwilligung (Art. 6 Abs. 1 lit. a DSGVO, § 25 Abs. 1 TDDDG); für die Prüfung auf deinen Klick dein ausdrücklicher Wunsch (§ 25 Abs. 2 Nr. 2 TDDDG) und das berechtigte Interesse, dir die angefragte Information zu liefern (Art. 6 Abs. 1 lit. f DSGVO).

**Empfänger:** GitHub, Inc., 88 Colin P. Kelly Jr. Street, San Francisco, CA 94107, USA (ein Unternehmen von Microsoft). GitHub verarbeitet die Daten nach seiner eigenen [Datenschutzerklärung](https://docs.github.com/de/site-policy/privacy-policies/github-general-privacy-statement).

**Übermittlung in die USA:** GitHub stützt Übermittlungen aus der EU nach eigenen Angaben auf das EU-US Data Privacy Framework (Angemessenheitsbeschluss der EU-Kommission vom 10. Juli 2023) und auf Standardvertragsklauseln.

**Speicherdauer:** Der Entwickler speichert keine dieser Daten und hat keinen Zugriff auf GitHubs Protokolle. GitHub zeigt dem Entwickler lediglich eine anonyme Gesamtzahl der Downloads je Datei. Wie lange GitHub Protokolle aufbewahrt, regelt GitHubs Datenschutzerklärung.

**Widerruf:** Du kannst die Einwilligung jederzeit widerrufen, indem du unter _Einstellungen → Über Write_ den Schalter _Automatisch nach Updates suchen_ ausschaltest. Der Widerruf gilt für die Zukunft.

## 5. Links und Fehlermeldungen

Links in Write (z. B. zu GitHub oder zum Impressum) öffnen sich in deinem Browser; dort gelten die Datenschutzbestimmungen der jeweiligen Seite. Wenn du über _Fehler melden_ ein Issue auf GitHub anlegst, ist dessen Inhalt öffentlich und unterliegt GitHubs Bedingungen.

Du hast das Recht auf Auskunft (Art. 15 DSGVO), Berichtigung (Art. 16), Löschung (Art. 17), Einschränkung der Verarbeitung (Art. 18), Widerspruch (Art. 21) und Widerruf einer Einwilligung (Art. 7 Abs. 3). Da der Entwickler keine personenbezogenen Daten über dich speichert, wird eine Auskunft in der Regel ergeben, dass keine Daten vorliegen; Anfragen zu den Daten bei GitHub richtest du am besten direkt an GitHub.

Du kannst dich außerdem bei einer Datenschutz-Aufsichtsbehörde beschweren (Art. 77 DSGVO), insbesondere in dem Bundesland bzw. Staat, in dem du wohnst.

# Privacy Policy for Write

As of 6 October 2026. The German version above is authoritative.

**Controller:** Jochen Enderlein – address and contact in the [legal notice](https://beerball.jochens-toller-server.de/impressum).

**In short:** Write runs on your Mac. There is no account, no telemetry, no analytics and no advertising. Your notes, search index, version history and settings stay on your device or in the folder you choose. The developer receives none of this data. If your folder lives in iCloud, Dropbox, Nextcloud or similar, that service syncs it under its own terms; Write is not involved.

**Update check:** The only connection Write makes on its own is to GitHub, to look for and download new versions – automatically (at launch and daily) only if you allowed it, otherwise only when you click _Check for Updates_. GitHub receives your IP address, the time, a technical client identifier (`electron-builder`) and which files are requested; when an update is downloaded, the installed version can be inferred. Note contents, file names and settings are never sent. Legal basis: your consent for automatic checks (Art. 6(1)(a) GDPR, § 25(1) TDDDG); for checks you start yourself, your explicit request (§ 25(2) no. 2 TDDDG) and the legitimate interest in answering it (Art. 6(1)(f) GDPR). Recipient: GitHub, Inc., San Francisco, USA (Microsoft), under its [privacy statement](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement); transfers rely, according to GitHub, on the EU-US Data Privacy Framework and standard contractual clauses. The developer stores nothing and only sees anonymous download counts. Withdraw consent anytime with the switch under _Settings → About Write_.

**Links and issues:** Links open in your browser under that site's policy. Issues filed on GitHub are public.

**Your rights:** access, rectification, erasure, restriction, objection, withdrawal of consent (Art. 15–18, 21, 7(3) GDPR) and a complaint to a supervisory authority (Art. 77 GDPR). Since the developer holds no personal data about you, an access request will usually show that none exists.
